# Anonymous CSIR@CoRL2026 project page

Static video supplementary page. Serve the repository root with any static web server.

All fonts are local TeX Gyre Pagella files. Published media and the extracted paper figure have identifying metadata removed; keep filenames, page content, and commit authorship anonymous.

Simulation comparisons come from the video collection's Markdown tables. Their main values describe the displayed rollout; captions describe the displayed executions. Real-robot figures are aggregate evaluation results shown alongside illustrative edited excerpts. Preserve outcome labels, measurement scope, and unknown units when updating comparisons.

Safety comparisons use the accompanying Markdown summary: Base is accumulated-data BC, and QCP uses hazard conditioning. Closest approach is distance to the center of a 9 cm hazard region. The displayed distances describe the shown rollouts. These selected simulation examples illustrate hazard avoidance and do not establish real-world safety.

Horizontal trackpad gestures, navigation buttons, and arrow keys wrap around the comparison gallery. Vertical page scrolling remains available.

Page copy and optional desktop/mobile text layouts are stored in `assets/content.json`. Text is rendered as plain text, and layout values are bounded. The public site contains no editing credentials or publishing endpoint.
